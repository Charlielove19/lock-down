# Lock Down

A small arcade game built in Godot 4.

The player places walls to keep a constantly moving ball inside the arena. Walls cost money to place, but earn money whenever the ball bounces off them. Walls have limited durability, creating a loop of placing, earning and replacing walls.

## Current Features

- Ball movement and physics-based bouncing
- Free wall placement using drag and drop
- Wall rotation during placement
- Wall health and damage
- Money earned from wall collisions
- Different wall properties such as cost, durability and reward
- Basic HUD and placement previews

## Planned Features

- Prevent overlapping/invalid wall placement
- Improved sprites, animations and visual feedback
- Multiple wall types and a wall-selection menu
- Unlockable walls based on progression
- Bonus items that reward redirecting the ball through them
- Game-over conditions and scoring
- Audio and general game feel/polish

## About

This is a learning project I'm using to improve my Godot and game-development skills, with a focus on building systems from scratch and iterating on the game design as I go.

Built with **Godot 4** and **GDScript**.
